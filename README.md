# ⚽ Ultimate Football Manager

HTML5ベースのサッカークラブ経営ゲームです。フォーメーション編成、移籍市場、カードパック、リーグ戦、クラブのカスタマイズなどが楽しめます。

## 遊び方（ローカルで開く）

`index.html` をダブルクリックしてブラウザで開くだけで遊べます。インターネット接続が必要です（見た目のためにTailwind CSS・FontAwesome・Google FontsをCDNから読み込んでいます）。

## 開発について

このゲームは1つのファイル `index.html` にすべて（HTML・CSS・JavaScript）が入っています。

- **見た目（レイアウト・色）**: `<body>` の中のHTMLと、`class="..."` に書かれたTailwindのクラス
- **ゲームのしくみ（ルール・データ）**: 一番下の `<script>` の中のJavaScript
  - `NATIONS_DATA` … 国とリーグのデータ
  - `STARTER_PLAYERS` … 最初の11人の選手
  - `MARKET_PLAYERS_DATABASE` … 移籍市場で買える選手たち

### 主な機能

| 機能 | 説明 |
| --- | --- |
| スカッド編成 | ピッチ上のポジションをタップして選手を配置（4-3-3） |
| 移籍市場 | 実在の有名選手を予算内で購入 |
| カードパック | 7枚入りパックを開封（レア度の重み付きガチャ） |
| リーグ戦 | 20チームのリーグで昇格・ヨーロッパ大会を目指す |
| 試合シミュレーション | 3Dスタジアムで試合を観戦（Fast / Extended）。カメラ3種類・フルスクリーン対応 |
| ゴールリプレイ | 得点すると自動でスローモーション再生（カメラが旋回） |
| スコアボード | 3D画面内に実況風スコアボード（チーム名・得点・時計） |
| クラブカスタマイズ | クラブ名・エンブレム・キット・スタジアム名 |
| セーブ／ロード | ブラウザ保存＋セーブコードの書き出し／読み込み |

## セーブデータについて

進行状況はブラウザの `localStorage` に保存されます。別の端末に移すときは「Save Code」機能でコードを書き出して持ち運べます。
